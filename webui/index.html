PIA WireGuard Config Generator

Regions slower than this are marked unreachable. 50ms is the same default the CLI scripts use; raise it if your connection has high latency.
Generates the config, then briefly brings up a real WireGuard tunnel on this Mac to confirm it actually handshakes before handing you the file. A native macOS authorization prompt (Touch ID capable) will appear — your password never passes through this page or server. Can take up to a minute.

Router login (test only)

Checks that this Mac can reach your router's local Network app and logs in — a Ubiquiti SSO-linked account may need a verification code as a second step. Does not change any router configuration — pushing the generated config to the router automatically isn't built yet (see HANDOFF.md).
This account needs a verification code to finish logging in. Check email/authenticator, enter the code, then submit again.

Push to router

Adds the generated config above as a new WireGuard VPN Client entry on the router (Settings → VPN in the Network app), using its real "Add WireGuard VPN Client" request. Needs a successful "Test Login" above first. 

  
  
Preview shows the exact request first — including the private key, since it's your own config. Apply is a separate, explicit step that actually writes it to the router.
